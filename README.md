# To-Do Web App & Login Authentication System

A simple and interactive web application developed using **HTML5, CSS3, and JavaScript** as part of an internship project. The project combines a **task management system** with a **client-side login authentication system**, demonstrating practical knowledge of DOM manipulation, form validation, localStorage, and user interface development.

## 🚀 Projects Included

### 6. To-Do Web App

The To-Do Web App allows users to efficiently manage their daily tasks. Users can add new tasks, edit existing tasks, mark tasks as completed, and delete tasks.

### Key Features

* Add new tasks using an input field
* Display newly added tasks under **Pending Tasks**
* Mark tasks as completed
* Automatically move completed tasks to the **Completed Tasks** section
* Edit task names inline
* Delete tasks from either list
* Display pending and completed task counts
* Friendly empty-state messages
* Task timestamps
* Tasks persist after page refresh using **localStorage**

## 🔐 7. Login Authentication System

The Login Authentication System provides a basic user registration and login workflow using HTML, CSS, and JavaScript.

### Key Features

* User registration with username/email and password
* Password validation
* Minimum 8-character password requirement
* Password must contain at least one number
* Duplicate username/email validation
* Login credential validation
* Clear error messages for incorrect credentials
* Protected dashboard page
* Session management using `localStorage`
* Logout functionality
* Form validation for empty fields
* Basic password hashing approach
