## Project Overview

### 1. Landing Page
A modern promotional landing page designed to present a product or brand in a visually appealing and professional way.

Features:
- Hero section
- Informational sections
- Call-to-action buttons
- Responsive layout

### 2. Personal Portfolio
A personal portfolio webpage created to showcase skills, projects, profile information, and contact details.

Features:
- About section
- Skills section
- Projects section
- Contact section
- Clean personal branding layout

### 3. Temperature Converter
A small JavaScript-based utility that converts temperature values between Celsius, Fahrenheit, and Kelvin.

Features:
- Input field for temperature
- Unit conversion logic
- Real-time conversion output
- Simple and user-friendly interface

### 4. Calculator
A functional calculator built with JavaScript for basic arithmetic operations.

Features:
- Addition, subtraction, multiplication, and division
- Clear and delete actions
- Responsive design
- User-friendly calculation interface

### 5. Tribute Page
A tribute page dedicated to Ada Lovelace, highlighting her contributions to computing and mathematics.

Features:
- Elegant themed design
- Biography and timeline sections
- Motivational quote section
- Responsive layout
